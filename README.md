# Road to WWII

Interactive review + quiz site for *The Causes of World War II* (Set 1, pages 1–6).
二戰成因溫習及測驗網頁（英文為主、中文為輔）。

- `src/` source files — question bank is `src/1-data.js` (the `DATA` array)
- `./build.sh` builds `二戰成因溫習.html` (single file), `index.html` (artifact) and `docs/index.html` (GitHub Pages)
